# Hackathon archive

These files describe the L’Ayalga demo that the AWS Agents for Humans judges reviewed. They record the product, evidence and submission copy as of 2026-10-14, when the judging period closed. They do not describe current behavior.

The judged product ran in demo mode: a public "Enter as Host" and "Enter as Guest" sign-in, a shared synthetic household, a guided demo and a demo clock. The real-use launch removes all of these: Google becomes the only sign-in, and the household holds real data. For current behavior, read the [root README](../../../README.md), the [host manual](../../guides/host-manual.md), the [guest manual](../../guides/guest-manual.md) and the [documentation index](../../README.md).

Links from these files to source code point to the `v1.3.11` release tag, the version that was live during judging. Links to other documents point to the current version of those documents.
